# Tests

Test projects for the sample go here, one folder per project (e.g. `tests/Kaleido.Samples.ECommerce.UnitTests`),
added to `Kaleido.Samples.ECommerce.slnx` so CI builds and runs them.

The sample has no .NET test project yet. The UI's tests live with the app (`ui/src/**/*.spec.ts`,
`npm test` in `ui/`).
